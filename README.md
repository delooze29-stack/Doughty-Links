# Doughty's Links

A 3D golf game in your browser: four courses (Kingfisher Links, The Master Course, Heather Ridge, Little Wren pitch and putt), practice holes, a driving range, replays, a golf buggy, weather and an online leaderboard.

Play it at https://delooze29-stack.github.io/Doughty-Links/

Leaderboard scores are saved to the ScoreKer Firebase project, collection `kfl_rounds` (rules live in the scoreker repo's `firestore.rules`).
